# 狐闹山海

微信小游戏策划与 AI 辅助开发规则文档。目标平台为微信小游戏，目标引擎为 Cocos，画面为竖屏 2D。

## 项目定位

轻松、可爱、国风山水/水墨气质的修仙放置游戏。核心循环是补充灵斧、砍仙树获得装备、当场比较并换装或分解、培养角色与仙树、挑战爬塔关卡。

《寻道大千》仅作为玩法品类参考。不得复制其美术资产、图标、文案、角色、界面构图或具体数值。

## AI 开发约定

1. 先阅读本文件和相关系统文档，再开始实现。
2. `已确认`代表用户明确选择或纠正的规则；不得擅自改变。
3. `数值原型`是当前可用于首版实现/模拟的起点，不代表已完成平衡。改动前应先验证并说明依据。
4. `待定`代表尚无决定。不要自行把建议或空白补成产品规则；遇到影响实现的选择时先询问。
5. 本文档中存在更晚的明确修订时，以较晚修订为准；被修订的旧规则不再适用。
6. 保持代码、数据配置和文档一致。影响玩法规则时同步更新对应文档。
7. UI 以视觉表达为先，避免常驻长篇说明；解释放入页面内的“？”入口。
8. 未经明确要求，不增加付费货币、抽卡、装备背包囤积或其他改变核心经济的系统。

## 规则状态

本文档不是最终数值平衡表。战斗时长、掉率、资源曲线、强化成本、签到数量等仍需模拟、原型测试或后续讨论。
