# 游戏概览与决策约定

## 游戏定位

| 项目 | 当前设定 |
|---|---|
| 暂定名称 | 狐闹山海 |
| 平台 | 微信小游戏 |
| 技术目标 | Cocos、竖屏 2D |
| 类型 | 轻松国风修仙、挂机成长、砍树掉装备、爬塔挑战 |
| 美术方向 | 国风山水或水墨风，角色轻松可爱 |
| 参考产品 | 《寻道大千》，只参考玩法便利性，不复刻其表达 |

玩家开局可选狐狸、熊猫或兔妖。当前规则是外观与表现差异，不提供职业强弱差异。

## 核心体验

1. 用灵斧触发砍树。
2. 每次砍树获得一件装备。
3. 立即比较新旧装备：换上其中一件，并分解另一件。
4. 通过装备、等级、技能、仙树与强化成长。
5. 挑战爬塔关卡，解锁更高品质装备与新成长内容。

装备只通过砍树获得；关卡奖励不直接发装备。

## 规则状态定义

- **已确认**：用户明确同意或直接指定的产品规则。
- **数值原型**：目前有具体数字，但仍需模拟和平衡测试。
- **待定**：尚未选择，或存在多个合理方案。
- **已废弃**：被更晚的用户决定覆盖，不得实现。

当一项规则同时有概念决定和未定数值时，应分别标记。例如“每次砍树必掉装备”已确认，但各品质实际概率仍需校准。

## 全局约束

- 不用推荐战力作为挑战硬门槛；战力是参考指标，不直接决定胜负。
- 避免重复刷已通关关卡产出首通资源。
- 不通过离线系统自动砍树或发放装备。
- 玩法数值均为本作原型，不得声称来自参考游戏的官方数据。
- 视觉、文案、角色、图标与界面构图必须原创。
