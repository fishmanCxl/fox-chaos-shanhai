# 界面、美术与动效规范

## 全局 UI 原则

- 视觉表达优先，避免常驻长篇文字说明。
- 用图标、颜色、状态条、动效和操作反馈传达信息。
- 必要说明放在当前页面的“？”按钮里，点击后显示简短说明。
- 新手教学优先高亮、指向和实际操作，不堆文字教程。
- 页面、弹窗、装备和奖励状态变化都要平滑过渡，避免生硬跳变。

## 美术基调与原创要求

- 整体采用国风山水或水墨风，轻松可爱，与山海志怪修仙主题统一。
- 《寻道大千》只借鉴玩法便利性，不复制其仙树造型、按钮、图标、角色、文案或页面构图。
- UI 组件、图标、角色、特效均为本作原创。
- 动画类似 CSS transition 的平滑状态过渡；需服务于信息反馈，不为动而动。

## 首页

### 顶部与活动入口

- 顶部显示个人头像、战力、灵斧（带“+”补充入口）和铜钱。
- 不显示灵玉或其他付费货币。
- 个人信息区域下方设置独立“活动”入口。
- 境界进度显示在主画面下方；攻击、生命、防御等详细属性从头像/属性区点开查看。

### 中央主视觉与砍树

- 夜海浮岛、月光仙树的山水/水墨场景。
- 仙树居中，角色站在树根前。
- 砍树灵器为错位双玉环与狐火晶核，不使用斧头作为核心视觉。
- 灵器悬浮在角色与树之间；点击底部中央灵器按钮触发砍树。
- 砍击时灵器发出灵光击中树干，掉落光效朝装备处理区域飞去。
- 每次砍树触发平滑的蓄势、出击、命中、掉落反馈。

### 装备格与底部导航

- 首页装备格常驻 3×3 显示 9 个装备部位。
- 已装备格显示图标、品质背景/边框和强化等级；品质背景也染色，高品质附轻微辉光。
- 空槽显示部位剪影和短名称；装备后可隐藏名称以减少拥挤。
- 点击格子打开装备详情/替换。
- 底部导航入口：爬塔、修炼、技能、装备、任务；装备放在技能与任务之间。
- 砍树按钮为底部中央高优先级操作。

## 装备页

- 独立铁匠铺风格页面，用于强化装备。
- 下方 9 件装备横向滑动选择，当前选择居中高亮。
- 上方铁匠区域在锻台展示选中装备，显示强化等级、成功率、消耗、稀有道具开关和强化按钮。
- 品质背景与装备品质一致。
- 强化成功/失败、数值变化与保底增长使用平滑动效。

## 爬塔页

- 纵向山路节点；每区 4 个小节节点后接首领节点。
- 普通/困难在顶部切换，共用同一张路线图。
- 当前可挑战节点突出显示，通关节点点亮，未解锁区域剪影/锁定。
- 点节点出现轻量预览：怪物立绘、首通奖励图标、挑战按钮。

## 技能与修炼页

- 技能页顶部 3 个已装备槽，下面是已解锁技能图标网格。
- 拖拽可更换与排序；槽位从左到右就是自动释放顺序。
- 未解锁技能显示剪影和解锁关卡。
- 技能升级弹窗展示当前/升级后效果、修为与残页消耗、升级按钮；复杂说明放“？”。
- 修炼页聚焦角色等级/境界和经验进度；经验自动升级，不设手动突破按钮。
- 修炼页可表现角色在月下灵台修炼，升级时显示属性变化和突破光效。

## 任务与活动页

- 任务页分“每日 / 每周 / 里程碑”三个页签。
- 任务项展示进度、奖励图标和领取按钮；每日/每周可“全部领取”，里程碑逐项领取。
- 首页活动入口打开活动页，分“签到 / 限时活动”；首版先做签到，限时活动暂不实现。
- 签到用 7 张横向/可滑动奖励卡；已领置灰、今日可领高亮、之后日期锁态。

## 战斗页

- 使用完整对战大场景，中间展示角色与怪物。
- 顶部显示回合与双方血条。
- 底部为技能栏、能量、普攻、自动开关及 1×/2×速度。
- 双方雷达属性图不使用，替换为技能栏。
