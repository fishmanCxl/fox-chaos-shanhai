# 新手引导、离线、广告与活动

## 新手引导

- 首次引导必须完成，不提供跳过或“稍后再学”。
- 引导严格按手势步骤推进；当前步骤之外的入口不可操作。
- 手势出现时显示全屏蒙层，其他区域暗化；只允许点击手势指向的目标，其他触摸全部拦截。
- 当前动作完成后，平滑移动高亮与手势到下一目标。
- 新手流程总时长目标约 3–5 分钟。
- 开局角色选择后，手势引导前三次砍树：武器、头盔、上衣；再教穿戴与进入爬塔。
- 不为了教程强塞重复掉落。第一次真实出现可分解装备时，再引导分解。
- 战斗教学先教普攻和手动释放技能。自动战斗的广告解锁是可选项，不阻塞教程。
- 战斗教学的完整步骤/触发条件仍应在原型阶段验收；不要擅自让用户必须观看广告才能完成引导。

## 自动砍树

- 自动砍树需单独观看一次广告永久解锁，与战斗自动解锁分开。
- 开启后只在前台首页运行；离开首页或切到后台暂停，回来需重新开启。
- 每 3 秒攻击一次（节奏原型）。
- 每次正常消耗灵斧并照常获得装备。
- 自动过程中掉落装备先进入临时处理队列，不自动换装/分解。
- 手动关闭或灵斧耗尽后，先处理战力提升最高的掉落，其他按获得顺序逐件处理。
- 处理装备时暂停自动砍树。

## 离线收益

- 离线最多累计 12 小时。
- 按当前最高塔关决定每小时收益；时长不足 1 小时按比例计算。
- 仅发修为和铜钱，不自动砍树、不掉装备。
- 收取后累计时间清零。
- 提供普通领取和看广告双倍领取；广告仅翻倍本次离线修为/铜钱。
- 上线显示简洁收益卡片和奖励飞入资源栏的动效。

## 广告解锁/补充规则

| 功能 | 广告规则 |
|---|---|
| 灵斧补充 | 可重复观看，补到 60，不超过 60；满时无效按钮隐藏或置灰 |
| 战斗自动 | 单独观看一次，永久解锁 |
| 自动砍树 | 单独观看一次，永久解锁 |
| 离线双倍 | 每次领取可选看广告双倍 |
| 仙树升级加速 | 每次广告减少固定 1 小时，可重复观看，按剩余时间封顶 |
| 聚灵石/护脉符 | 不放进广告奖励 |

广告失败不得伪装成成功，也不得扣除未完成的奖励/翻倍次数。

## 7 日签到

- 首页个人信息区域下方有活动入口；签到在活动页内，不放进任务页，也不增加底部导航。
- 活动页分“签到 / 限时活动”；首版实现签到，限时活动暂缓。
- 7 日循环奖励逐步递增，奖励类别包括灵斧、铜钱、仙树材料、常规强化材料；第 7 天额外给技能残页。
- 每日奖励数量尚未定，不得自行补数值。
- 当天奖励免费领取后，可看广告补领等量奖励；每个自然日最多翻倍一次。广告失败不消耗次数，也不影响基础领取。
- 当天已出现但未领取的奖励保留；漏掉的自然日不补签，不重置后续进度。
- 签到不发聚灵石或护脉符。
